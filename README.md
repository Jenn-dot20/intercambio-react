# Rota Mundo — frontend de TCC

Frontend acadêmico para uma plataforma de orientação de intercâmbio, criado com React, Vite e React Router DOM.

A interface foi simplificada para usar elementos HTML padrão, sem folhas de estilo CSS.

## Telas e responsáveis

- **Tela inicial / página de apresentação** — responsável: **[Nome do integrante 1]**. Substitua pelo nome do integrante responsável.
- **Tela de login** — responsável: **[Nome do integrante 2]**. Substitua pelo nome do integrante responsável.

Cada integrante deve entregar sua tela individualmente no GitHub. Atualize os nomes antes da entrega.

## Executar

1. Instale as dependências com `npm install`.
2. Inicie o servidor com `npm run dev`.
3. Abra o endereço local indicado no terminal.
4. Gere a versão de produção com `npm run build`.

## Rotas

- `/` — página inicial, destinos em destaque e etapas de planejamento.
- `/login` — formulário de acesso demonstrativo.

O login nesta primeira entrega é apenas uma simulação no navegador e não autentica usuários em um servidor. O e-mail é opcional; informe uma senha com pelo menos quatro caracteres. Não use dados reais.
